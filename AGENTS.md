# Repository guidance

- Write all source code, comments, documentation, tests, commit messages and user-interface text in English.
- Keep the neural-network calculations real and inspectable. Do not replace inference or training with geometric rules or simulated metrics.
- Preserve browser-only inference and local model persistence.
- Run `npm test` and `npm run build` after behavioral changes.
- Keep the interface educational: visual values must derive from actual weights, activations or training updates.
